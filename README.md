# Wick Player — Wispbyte

## التشغيل
1. ارفع جميع الملفات والمجلدات إلى المجلد الرئيسي في Wispbyte.
2. في `config.js` ضع `token` و`clientId` الخاصين ببوتك.
3. تأكد من تفعيل Message Content Intent من Discord Developer Portal.
4. استخدم `npm install` ثم `npm start`.

## الأوامر
- `!play` / `!p` / `!ش` / `!شغل` / `!تشغيل`: تشغيل أغنية أو رابط.
- `!pause` / `!إيقاف`: إيقاف مؤقت.
- `!resume` / `!استئناف` / `!متابعة`: استئناف.
- `!skip` / `!s` / `!س` / `!سكب`: تخطي.
- `!stop` / `!توقف` / `!توقيف` / `!ت`: إيقاف ومسح القائمة.
- `!volume 0-200` / `!صوت 0-200` / `!v`: ضبط الصوت، و`!volume` لعرضه.
- `!vup` / `!vdown`: رفع أو خفض الصوت 10%.
- `!repeat` / `!loop` / `!تكرار`: تبديل التكرار.
- `!repeat song`, `!repeat queue`, `!repeat off`: اختيار وضع التكرار.
- `!unloop` / `!لتكرر`: إيقاف التكرار.
- `!nowplaying` / `!np` / `!الاغنية` / `!current`: الأغنية الحالية.
- `!queue` / `!q` / `!الاغاني`: قائمة الأغاني.
- `!clear` / `!c` / `!مسح`: مسح القائمة وإيقاف الموسيقى.
- `!remove رقم` / `!rm` / `!شيله`: حذف أغنية من القائمة.
- `!help` / `!مساعدة` / `!أوامر`: عرض المساعدة.

اللغة الافتراضية مضبوطة على العربية من `config.js`. لا تشارك توكن البوت مع أحد.


## إعداد التوكن على Wispbyte (بدون وضعه داخل الكود)

من لوحة Wispbyte افتح قسم **Variables / Environment Variables** وأضف المتغيرين التاليين:

- `DISCORD_TOKEN` = توكن بوت Discord الخاص بك
- `CLIENT_ID` = Application ID الخاص بالتطبيق

احفظ المتغيرات ثم أعد تشغيل البوت. لا تضع التوكن داخل `config.js` ولا تشاركه مع أحد.
